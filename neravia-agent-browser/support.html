How can we help?

Neravia Agent Browser is a native Mac workspace for visible, private AI browser sessions.

Start an agent run

  1. Make sure Apple Intelligence is enabled and ready in System Settings.
  2. Enter a clear web goal in the Agent panel.
  3. Choose Run and follow the visible page and activity timeline.
  4. Review any requested click or field edit, then choose Allow once or Decline.

No account, API key, AI subscription or provider setup is required.

System requirements

Manual WebKit browsing works on macOS 14 and newer. AI agent mode requires macOS 26 or newer, a compatible Apple silicon Mac, Apple Intelligence enabled, and its on-device model ready. The app shows the current model status in the Agent panel and Settings.

An agent pauses

Clicks and typing require one-time approval. Review the visible page, then choose Allow once or Decline. A declined action is returned to the local agent so it can choose a safer path.

Troubleshooting

  • Open System Settings and confirm Apple Intelligence is enabled.
  • If the model is still downloading, wait until Apple Intelligence finishes preparing, then choose Check Again in Neravia Settings.
  • Reduce the goal to one website and one clear outcome.
  • Use the address field for ordinary manual browsing when agent mode is unavailable.
