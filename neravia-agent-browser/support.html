How can we help?

Neravia Agent Browser is a native Mac workspace for visible AI browser sessions.

Connect Kimi K3

  1. Create a TokenRouter API key.
  2. Open Settings in Neravia Agent Browser.
  3. Choose Kimi K3 Free or Kimi K3.
  4. Paste the key and choose Save to Keychain.

The app never writes the key to session history or ordinary files.

Connect Lightpanda

Start a Lightpanda MCP server separately, then enable Lightpanda in Settings and enter its MCP HTTP endpoint. Use local HTTP only for localhost or 127.0.0.1. Use HTTPS for remote servers. Lightpanda is optional; visible WebKit browsing works without it.

An agent pauses

Clicks, typing and potentially changing Lightpanda tools require one-time approval. Review the visible page, then choose Allow once or Decline. A declined action is returned to Kimi so it can choose a safer path.

Troubleshooting

  • Confirm the TokenRouter key is active and the account has access to the selected model.
  • Try Kimi K3 Free for the simplest first run.
  • Reduce the goal to one website and one clear outcome.
  • If Lightpanda is unavailable, disable it and retry with the built-in browser.
