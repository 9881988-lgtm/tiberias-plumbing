# SEO лендинг: солнечные бойлеры в Тверии

Полноценный SEO-лендинг с воронкой заявки для услуги `מים ושמש - דודי שמש`: продажа и установка солнечных бойлеров, коллекторов и водяных подключений в Тверии. Основной язык - иврит, русский включается кнопкой.

## Что внутри

- Статический лендинг: `index.html`, `styles.css`, `script.js`.
- Сгенерированный hero-asset: `assets/solar-boiler-tiberias-hero.png`.
- JSON-LD schema.org для `HomeAndConstructionBusiness`, `Plumber`, `WebSite`, `WebPage` и `FAQPage`.
- Контакты и WhatsApp взяты из предыдущей воронки: `+972-53-361-31-00`.
- Цена услуги: солнечный бойлер начинается от `2,200 ₪`; промокод `שמש2200` дает скидку `100 ₪`.
- Форма заявки собирает имя, телефон, адрес, район, тип запроса, выбранный слот, канал связи и комментарий.
- Google Apps Script backend подготовлен в `google-apps-script/`: выдает слоты, создает событие календаря, отправляет email и может писать заявку в Google Sheet.

## Файлы

- `index.html` - SEO-разметка, контент, форма и FAQ.
- `styles.css` - responsive-дизайн лендинга.
- `script.js` - переключение языка, выбор свободного слота, WhatsApp/email fallback и отправка на Google Apps Script.
- `robots.txt`, `sitemap.xml` - базовые SEO-файлы.
- `google-apps-script/Code.gs` - backend для свободных слотов, email + Google Calendar.

## Подключение backend

1. Создайте Google Apps Script Web App по инструкции в `google-apps-script/README.md`.
2. Вставьте Web App URL в `SETTINGS.googleScriptUrl` внутри `script.js`.
3. Укажите `SETTINGS.ownerEmail`, если хотите email fallback через `mailto:`.
4. В `google-apps-script/Code.gs` замените `OWNER_EMAIL` и при необходимости `CALENDAR_ID` / `SHEET_ID`.

До подключения `SETTINGS.googleScriptUrl` форма показывает локальные демо-слоты по графику воскресенье-четверг: `09:00`, `12:00`, `15:00`. После подключения Apps Script эти слоты заменяются реальной доступностью из Google Calendar.

## Важное про WhatsApp

Бесплатный Google Apps Script не отправляет WhatsApp-сообщения сам. Сейчас лендинг открывает готовое сообщение WhatsApp с данными заявки и подтверждением стартовой цены. Для автоматической отправки от бизнеса нужен WhatsApp Business API, Twilio, Make/Zapier или другой провайдер.

## Google Business Profile

В старой воронке был указан тот же путь для Google Business Profile: `https://business.google.com/`. Публичная ссылка на карточку в файлах не была сохранена, поэтому для этой услуги лучше обновить тот же существующий профиль `מים ושמש` в Google Business:

- добавить услугу `דודי שמש` / `התקנת דוד שמש`;
- поставить цену `החל מ-2,200 ₪`; добавить промокод `שמש2200` на скидку `100 ₪`;
- оставить телефон `+972-53-361-31-00`;
- добавить ссылку на новый лендинг после публикации;
- не создавать новый профиль, чтобы не потерять историю аккаунта.
