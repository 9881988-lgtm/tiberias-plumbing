# Google Apps Script backend

Этот скрипт обслуживает backend-форму лендинга солнечных бойлеров: выдает свободные 3-часовые слоты из Google Calendar, принимает заявки, повторно проверяет выбранный клиентом слот, создает событие в календаре, отправляет email владельцу и при наличии email отправляет клиенту подтверждение стартовой цены `החל מ-3500 ₪`.

## Настройка

1. Откройте [script.google.com](https://script.google.com/) и создайте новый проект.
2. Вставьте содержимое `Code.gs`.
3. В `CONFIG` замените:
   - `OWNER_EMAIL` на email для заявок;
   - `CALENDAR_ID` на `primary` или ID нужного календаря;
   - `SHEET_ID`, если хотите дополнительно сохранять заявки в Google Sheet.
4. Нажмите Deploy -> New deployment -> Web app.
5. Execute as: `Me`.
6. Who has access: `Anyone`.
7. Скопируйте Web App URL.
8. В файле `script.js` лендинга вставьте URL в `SETTINGS.googleScriptUrl`.

## Поведение

- Рабочие часы сохранены из предыдущей воронки: воскресенье-четверг, `09:00-18:00`.
- Клиент выбирает дату и время на лендинге.
- Каждая заявка получает выбранный 3-часовой слот.
- Список свободных слотов отдается через `GET ?action=slots&callback=...`, поэтому статический сайт может читать доступность без CORS.
- Перед созданием события скрипт повторно проверяет, что выбранный слот входит в график и еще свободен.
- Если слот уже занят или вне графика, событие не создается, а владельцу приходит email об ошибке.
- WhatsApp без платного API не может автоматически отправлять сообщение клиенту. Лендинг открывает готовое WhatsApp-сообщение, а email-подтверждение отправляется автоматически, если клиент оставил email.

## Проверка слотов

После публикации Web App можно открыть:

```text
YOUR_WEB_APP_URL?action=slots&daysAhead=7
```

Должен вернуться JSON со свободными интервалами вида `09:00-12:00`, `12:00-15:00`, `15:00-18:00`.
