## Free hosting options

### Fastest: Netlify Drop

1. Open https://app.netlify.com/drop
2. Drag the entire `structo-robotics-site` folder into the page.
3. Netlify will publish the site and give a free public URL.

### GitHub Pages

1. Create a free GitHub repository.
2. Upload all files from this folder to the repository root.
3. In repository settings, open `Pages`.
4. Set source to `Deploy from a branch`, branch `main`, folder `/root`.
5. GitHub will provide a free URL.

### Cloudflare Pages

1. Create a free Cloudflare Pages project.
2. Upload this folder directly or connect a GitHub repository.
3. Use no build command.
4. Use `/` as the output directory.
