Edelstein CRM Israel Support

Free CRM for iPhone, iPad and Mac

Getting started

Choose an interface language, then add a contact, deal, task or appointment. No Edelstein account, subscription or Mac server is required.

Sync between iPhone and Mac

Sign in to the same Apple Account on both devices, enable iCloud Drive, and install Edelstein CRM from the App Store. Changes are stored locally first and sync through the app's private CloudKit container when a network connection is available.

Import from the earlier Golani CRM

Export a golani-crm-1 JSON file from the earlier CRM. In the new app open Settings → Import legacy Golani CRM JSON and select that file. Existing imported record IDs are skipped on repeated import.

Important limits

VAT figures are estimates. The app is not a certified Israeli invoicing system, payment processor, accounting service or tax adviser. Keep separate legally compliant invoices and backups appropriate for your business.
